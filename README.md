Five hands-on tasks completed as part of the **Cognifyz Technologies Full Stack Development Internship**, progressing from basic HTML forms to API-driven front-end interaction.

## Task details

### Task 1: HTML Structure and Basic Server Interaction
- A "Contact Us" page built with semantic HTML (name, email, message).
- The form submits to a local server (`/submit`), which returns a personalised "Thank you" page showing the submitted details.

### Task 2: Inline Styles, Basic Interaction, and Server-Side Validation
- A styled registration form with name, email, age, gender, country and a terms checkbox.
- Input is validated on the server before it is saved.
- A "View Users" page (`/users`) lists all registered users in a table.

### Task 3: Advanced CSS Styling and Responsive Design
- "Skillbridge", a landing page for an online learning platform.
- Sections: hero, popular courses, how learning works, stats and a sign-up form.
- Styled with advanced CSS (layout, spacing, typography and a consistent colour system).

### Task 4: Complex Form Validation and Dynamic DOM Manipulation
- A single-page app with Home, Sign Up and Tasks views.
- Sign Up form with live validation, a **password strength meter** (Weak / Medium / Strong) and a confirm-password check.
- Tasks view where tasks are added and deleted dynamically through DOM manipulation.

### Task 5: API Integration and Front-End Interaction
- "Book Manager" front end with **Create, Read, Update and Delete** operations.
- Books are saved, listed, edited and deleted through API calls.
